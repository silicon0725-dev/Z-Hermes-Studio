## 第二轮（run-20261017-0840 附近，Server GC + 样本 ×30）——当前结论

变更：`ServerGarbageCollection=true`（Desktop 与 Benchmarks）+ A 场景样本 10→30。

| 场景 | 1k | 10k | 50k | 对照目标 | 结论 |
|---|---|---|---|---|---|

- 首轮的 1.2s 级首屏离群在 Server GC + 加大样本后**完全消失**（Gen2 计数归零/大幅下降），归因确认：GC 暂停，非布局规模。
- 耗时与集合规模无关（50k 与 1k 同量级）——虚拟化在 50k 规模下依旧只实例化可视区。
- 仍未测（headless 无法测）：真实渲染帧率（16.7ms 连续滚动预算）、进程冷启动、会话切换取消过期加载。

## 首轮（run-20261017-081846，Workstation GC + 样本 ×10）——保留作对照

### A 首屏可交互（首页 60 条，热缓存口径，每档 ×10）

| 数据集 | P50 | P95 | 最差 | 结论 |
|---|---|---|---|---|
| 1,000 | 345.4 ms | 1383.3 ms | 1383.3 ms | P50 达标；P95 超标 |
| 10,000 | 91.3 ms | 1251.9 ms | 1251.9 ms | P50 达标；P95 超标 |
| 50,000 | 27.0 ms | 121.2 ms | 121.2 ms | **全档达标** |

关键观察：**耗时与集合规模无关**（50k 反而最快）——虚拟化生效，只有可视区被实例化。P95 尖峰与 GC 活动相关（1k/10k 档出现 Gen2 回收，1.2s 级离群；50k 档因数据集生成期间 GC 已提前发生而干净）。样本量 10 过小，P95 不稳定。

### B 批量追加（批大小 60，逐批布局）

| 数据集 | P50 | P95 | P99 | 最差 | 结论 |
|---|---|---|---|---|---|
| 1,000 | 1.3 ms | 4.9 ms | 4.9 ms | 4.9 ms | 达标 |
| 10,000 | 1.0 ms | 6.2 ms | 10.3 ms | 67.8 ms | 达标 |
| 50,000 | 0.5 ms | 6.6 ms | 18.1 ms | 51.2 ms | P95 达标；P99/最差为 GC 尖峰 |

单批布局中位数亚毫秒~毫秒级，远低于 8ms 单次同步预算与 16.7ms 帧预算。追加路径对集合规模不敏感。

### C 跳页滚动（中段↔底部 ×20）

| 数据集 | P50 | P95 | 最差 |
|---|---|---|---|
| 1,000 | 0 ms | 50.4 ms | 287.6 ms |
| 10,000 | 0 ms | 43.4 ms | 108.7 ms |
| 50,000 | 0 ms | 99.3 ms | 125.7 ms |

P50≈0 说明虚拟化正常工作（跳转目标已实例化时零布局成本）；跳入未实例化区域的单次成本 43–125ms（含再实例化 + GC）。这是跳页（一次性）成本而非连续滚动帧率；连续滚动帧率需真机渲染管线测量（headless 无法测真实帧）。

### P 管道吞吐（50,000 增量，容量 512，生产者未限速）

- 写入→接受 2,048/16,384 增量（逐次波动）、**合并为 3–4 批**、丢弃其余（设计行为：增量可丢，最终文本权威覆盖）。
- 吞吐 437–802 增量/ms。真实场景生产者是 1.5s 轮询批次，远低于此速率，丢弃不会发生。

## 结论与差距（ADR-0003 验收对照）

1. **达标**：批量追加（B）P95 ≤ 6.6ms；50k 首屏全分位达标；虚拟化确认生效（规模不敏感）。
2. **差距（可复现）**：首屏 P95 在 1k/10k 档出现 1.2s 级离群，证据指向 **GC**（Gen2 可见）而非布局规模。
3. **优化计划**：
   - 基准方法学：A 场景样本 10 → 100+，分离 GC 尖峰样本归因（记录 GC.GetTotalPauseDuration）；
   - 运行时：启用 Server GC / GC 区域模式并复测（桌面应用内存充足场景的常规项）；
   - UI：消息模板减重（当前 TextBlock 直排，已是轻量）；若后续加 Markdown 渲染，必须按 §7.3 延迟/局部更新；
   - 真机复测：headless 只测布局/调度，帧率（16.7ms 预算）与首帧需真实渲染管线数据。
4. **未测**：连续滚动帧时间分布、冷启动（进程级）、会话切换取消过期加载——随 M2 UI 完善补测。
